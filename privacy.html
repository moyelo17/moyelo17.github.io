Privacy Policy

Last updated: 10 November 2026 (public video information section added)

This policy covers the Next Open website and "Next Open Publisher", the internal software tool that publishes the Next Open YouTube channel (@NextOpenDaily).

Who uses Next Open Publisher

Next Open Publisher is used only by the owner of the Next Open channel, to manage that channel. It is not available to the public, and no other person can sign in to it or have their data accessed by it.

What data it accesses (Google / YouTube API)

With the channel owner's explicit permission, given through Google's sign-in screen, Next Open Publisher uses these Google permissions for the Next Open channel only:

  • Upload videos (youtube.upload) - to upload Next Open episodes, their titles, descriptions, tags and thumbnails to the Next Open channel.
  • View the YouTube account (youtube.readonly) - to confirm it is connected to the correct channel and to read the channel's own public video list and statistics.
  • View YouTube Analytics (yt-analytics.readonly) - to read the channel's own reports (views, watch time, average view duration, subscribers gained and lost) to improve the show.

It does not read, collect or store data about viewers or commenters, and it does not access email, contacts, files or any other Google service.

Public video information (no sign-in)

Separately, our research tools use a YouTube API key (no user sign-in) to read public information about a small number of similar finance channels - video titles, publish dates and view counts - to understand which topics viewers find useful. This public data is kept in local files on the owner's computer, is never displayed on any site, shared or sold, and is not used to train AI models.

How the data is used and stored

  • Channel statistics and analytics are stored on the channel owner's own computer, only to track the channel's progress and decide how to improve future episodes.
  • The Google sign-in token is stored on the same computer and is used only to perform the actions above.
  • The data is not sold, rented, shared with or transferred to any third party, and is not used for advertising.
  • Episode quality checks may send the channel's own episode text and preview images (never any user data) to AI review tools; no Google user data received through the YouTube API is used to develop, improve or train generalized AI or machine-learning models.

Google API Services User Data Policy

Next Open Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Next Open uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions (remove "Next Open Publisher"). Stored analytics and the sign-in token are kept only while the channel is active and are deleted from the owner's computer on request or when the tool is no longer used. To request deletion or ask any question, email the address below.

This website

This website has no accounts, no forms, no advertising and no tracking cookies. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) as described in GitHub's privacy statement.
